Per windows:

Scaricare Python manager
https://www.python.org/downloads/

Versione portable di python3
https://sourceforge.net/projects/portable-python/

Per installare le librerie
python.exe -m pip install fastapi==0.115.0 uvicorn[standard]==0.32.0 pandas==2.2.3 python-multipart==0.0.12




-------------------------------------------------------------------

Per avviare il server del chatbot
Vai nella pendrive <X>:\Python-3.10.5 x64\
ed esegui Console-Launcher.exe
Dal prompt vai in cd chatbot\backend

Per l'avvio
python -m uvicorn main:app --host 0.0.0.0 --port 8000

Per l'arresto
Ctrl-C

URL del chatbot
http://localhost:8000/
